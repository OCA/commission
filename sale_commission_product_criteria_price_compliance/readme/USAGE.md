To use this module, you need to:

1. Go to Commissions App > Configuration > Commision types.
1. Create a new Commission Type and set **Product criteria** on field Type.
1. On rules, select the rule that you want and choose Product Criteria Tier.
1. Create a Sale with an Agent and change price to change Product Criteria Tier.
1. Continue with the main workflow to create an effective settlement from a Sale.
1. Print settlement Report to see the Product Criteria Tier on each Settlement Line.
